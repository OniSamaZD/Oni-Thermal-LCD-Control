## ⚡ Faster startup and discovery

- Application shell appears asynchronously while discovery continues
- Native Windows device metadata enumeration replaces PowerShell/CIM in normal GUI discovery
- Native SCSI matching and stable physical-device identity
- Fast, fresh rescans without a persistent global topology cache

## 🛡 Reliability

- Native conflict-process enumeration; normal output restore/start no longer launches PowerShell
- Improved rescan and session lifecycle handling
- Side-by-Side responsiveness fixed for smaller windows
- Bounded latest-frame playback queues and stabilized static-frame caching

## 🖥 Physically verified displays

- Thermalright Trofeo Vision 9.16 LCD — `0416:5408`, WinUSB, `1920 × 462`
- Thermalright Trofeo Vision 6.86 LCD — `0416:5302`, HID, `1280 × 480`

Other catalog devices remain **Experimental** unless explicitly marked Verified.

ONI Thermal LCD Control is an independent project and is not an official Thermalright application.
